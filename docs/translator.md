# Экранный переводчик

Поверх экрана приложение рисует русские плашки на место надписей, которые прошивка показывает по-китайски или по-английски. Тексты берутся из дерева доступности, подмена идёт по словарю `assets/translate/<пакет>.json`:

```json
{"exact": {"声音模式": "Режим звука"},
 "patterns": [["^结果「(.+?)」：(.+?)$", "Результаты для «\\1»: \\2"]]}
```

Словари лежат в репозитории и входят в APK. Их основа — русский перевод строк прошивки из VIDDA Nova; его автор разрешил использовать этот перевод. Недостающее добавлено вручную и черновым переводом локальной нейросетью, короткие слова для узких меню — в `tools/overrides/`.

Инструменты в `tools/`:

- `build-dict.py` — собирает словарь пакета: берёт строки по умолчанию из его APK на проекторе (нужны `adb` и `aapt2`) и сопоставляет с вашим переводом тех же ресурсов по имени;
- `untranslated.py` — что в словарях осталось без перевода;
- `match-dicts.py`, `dict-specs.txt` — сопоставление файлов перевода с пакетами;
- `overrides/` — короткие русские слова для узких меню (правит длинные места вручную);
- `qwen-translate.py` — черновой перевод оставшегося локальной моделью.
